### Moonn

```text
  source ─▸ lexer ─▸ parser ─▸ AST ─▸ IR ─▸ codegen ─▸ bytes
```

I love compilers and interpreters — the machinery that turns text a person writes
into something a machine will run. I like following a system all the way down, from
source to bytes, and building the small, correct tools along that path.

Mostly Go, Rust, and C. Languages, compilers, static analysis, and the unglamorous
plumbing that simply has to be right.

**Built**

- [Cecile](https://github.com/your-moon/Cecile) — a programming language, in Rust.
- [mon_lang](https://github.com/your-moon/mon_lang) — the Mon language (Go), with [mon](https://github.com/your-moon/mon), a companion implementation in C.
- [gpc](https://github.com/your-moon/gpc) — a static preload checker for GORM: catches missing `Preload`s and N+1s at build time, not in production.
- [kaleidoscope](https://github.com/your-moon/kaleidoscope) — the LLVM front-end, built up from nothing in C++.
- [BolorToli](https://github.com/your-moon/BolorToli) — a Mongolian⇄English translation extension.

Currently working the whole pipeline end to end — interpreter, VM, compiler, LLVM,
assembly, syscalls, linking, loading — and writing it down as I go.
